# College ERP System

## Project Overview
College ERP is a project designed to manage basic college activities and student information.

## Features
1. Student Login
2. View Student Attendance
3. View Class Timetable
4. View Examination Schedule
5. Mark Student Attendance
6. Upload Study Material
7. Manage Student Records
8. View College Announcements

## Tools Used
1. Jira
2. GitHub
3. GitHub Actions

## Project Objective
To learn project management, sprint planning, version control, and CI/CD automation using DevOps tools.
